# PokeMob Battle

Mod de servidor para Minecraft 1.20.1 (Forge) + Cobblemon 1.5.x.

Agáchate y haz clic derecho sobre cualquier mob con un palo (configurable) para iniciar una batalla
Cobblemon contra un Pokémon "doble" del mob. Si ganas, el mob muere.

La configuración se crea sola en `config/pokemobbattle.json`.
